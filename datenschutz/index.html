Хостинг GitHub Pages

При открытии публичной версии браузер запрашивает файлы у GitHub Pages. GitHub получает IP-адрес, время и адрес запроса, а также технические сведения HTTP-запроса. GitHub сообщает, что IP-адреса посетителей регистрируются для безопасности, даже без входа в аккаунт GitHub.

Цель использования хостинга — доставка сайта и защита инфраструктуры. Правовое основание в части нашей обработки — Art. 6 Abs. 1 lit. f DSGVO: законный интерес в надёжной работе приложения. Собственных серверных журналов посещений приложения у нас нет. Хранение данных GitHub, получатели и международная передача регулируются политикой GitHub. Мы не устанавливаем сроки хранения журналов GitHub. Дополнительно: сбор данных GitHub Pages.

Избранное, рундук и закупка в браузере

В localStorage под ключом deelstuff-kombuese-v1 сохраняются выбранные продукты, избранные варианты рецептов, план готовок, список закупки с отметками и настройки конструктора. Сохранение нужно для восстановления выбранных вами функций при следующем открытии. Содержимое этих списков не отправляется владельцу сайта или в аналитику.

Выбранные данные остаются в этом браузере на этом устройстве, пока вы их не измените или не удалите данные сайта в настройках браузера. В приватном режиме и при запрете хранилища сохранение может быть недоступно. Для необходимых локальных функций применяется § 25 Abs. 2 Nr. 2 TDDDG; в части персональных данных — Art. 6 Abs. 1 lit. f DSGVO.

Работа без связи и сохранение PNG

Service worker сохраняет в Cache Storage файлы приложения, справочник, шрифты, иллюстрацию и правовые страницы, чтобы открывать уже подготовленное приложение без сети. Кеш хранится до обновления или удаления данных сайта; браузер может очистить его самостоятельно. Избранное и офлайн-кеш удаляются через настройки данных этого сайта в браузере.

PNG-карточка рецепта создаётся в браузере из выбранных вами ингредиентов и шагов и скачивается на устройство. Для создания изображения рецепт не отправляется внешнему сервису. Иллюстрация камбуза была сгенерирована заранее и загружается как обычный локальный файл сайта.

Шрифты, внешние ссылки и аналитика

Шрифты, изображения и значки загружаются с самого приложения. Рекламных cookies, аналитических счётчиков, встроенных карт, видео и внешних генераторов изображений в приложении нет. Текстовые ссылки на источники не загружают их содержимое заранее. Если вы переходите по внешней ссылке, обработку данных на открытом сайте определяет его оператор.

Основной журнал deelstuff — отдельный сайт со своим описанием обработки данных. Указанные там счётчик и карты не подключены к этому приложению.
